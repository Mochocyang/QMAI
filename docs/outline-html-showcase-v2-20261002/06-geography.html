06 / 地理设定 / 第二版

北境雾海不只知道哪里有什么，还要知道人怎样走、货怎样到、边界怎样起作用。

海不是背景，而是运转世界的道路。白帆港连接粮田、矿山与群岛；航灯一旦熄灭，改变的不只是风景，而是粮价、权力与每个人回家的时间。

中心为什么在这里

白帆港天然深水湾便于大船停泊，近河口方便粮食转运，靠丘提供避风地。但旧城沿坡狭窄，货车与行人容易在税门冲突。

自然与政治边界

灰脊分水岭是清楚的自然障碍，矿联债权却延伸到港口；群岛海面没有围墙，实际控制取决于巡航、灯塔和补给。

中心与边缘

港城汇集信息，但边缘地区不只是等待拯救。岛民掌握潮窗，矿工了解地下水，知识通过交易进入中心。

未知地带

禁海之外不画出密集城市。第一卷没有验证过的海域保留空白，新增地区必须说明如何获知。

03

区域划分

每个地方都需要人口、生产、气候和行动规则。

01 / 西北 · 矿业与关隘

灰脊山地

山口地势高，背风谷地聚落分散。耐盐石与煤矿分布不均，采矿营地依赖外来粮食。雨季滑坡、冬季冰路，使“有矿”不等于“随时能把矿送到港”。

中心
石门镇：货场、驿站、矿债仲裁处
边界
东侧为灰脊分水岭，南接芦汀北缘丘地
常住
矿工与家属住谷地，矿主住关内石屋
通行
主道经过石门关；废弃采矿路不适合载重驮队
02 / 西部 · 粮食、淡水与税闸

芦汀平原

雾河冲积田沿堤展开，地势低却土壤肥沃。粮仓不设在最低田边，而建在高堤内侧；汛期有人守堤，意味着同一家庭会失去田间劳力。

中心
苇桥集：粮食交易、渡口、水车修理
边界
自然河道与行政税区不完全重合
常住
佃户沿高堤住木屋，田主集中在集镇
通行
河道运力高，支渠水浅只通小舟
03 / 中部海岸 · 贸易与主舞台

白帆港

天然深水湾西侧靠丘，东面向海。旧城、会馆、东港和北堤相互连接，潮水决定低处能不能通行。这里不是均匀铺开的城，而是逐年填筑的岸线。

中心
东港：引港、装卸、税务检查集中
边界
港务署实际治理止于灯标内水域
常住
西巷租户、会舍成员、沿港商号混居
通行
北堤步行近但不能运重箱；正门道路可走货车
04 / 东南外海 · 盐田与航灯

盐风群岛

三类小岛分别承担盐田、居住与锚地功能。饮水从集雨池和船运而来，井水多数有咸味。顺风航程两日，恶劣天气时一条正常航线就会变成围困。

中心
盐风岛：集市、油料作坊、议事屋
边界
岛约按锚地与季节渔场划分权益
常住
高处石屋避浪，盐工季节性住田边工棚
通行
退潮礁间可步行，但没有全季陆桥
区域差异怎样进入正文

沈砚在港口靠证件进入仓库，在矿区靠工头担保通行，在群岛要先证明自己懂潮窗。身份的价值会随地区改变，不能到哪里都用同一句“我是潮灯会的人”解决。

04

重要地点

地理总览管连接，地点档案管内部规则。

地点所属与相对位置为何建在此处剧情与到达条件
潮汐书库白帆港东岸，会馆后方旧盐仓墙体耐潮，近船单登记点从西巷步行约三刻；原件查阅须登记。
北堤换灯亭港城东北侧堤顶避开主税门，观察外海雾线徒步近路；涨潮时下层小径关闭，重箱无法快速通过。
苇桥集雾河上游粮仓旁高堤与渡口连接两岸税区核对粮船航期；水闸晚放会多等半日。
石门关灰脊通港主道隘口地形收束，适合检验载重与收税查矿车出关记录；守军需看到雇主担保。
盐风灯岛主岛东侧一日小艇往返内岩基稳定，可建航灯、存雨水调查燃料与失灯原因；恶浪时大船不能靠岸。
第七灯塔东北禁海，准确入口仅作者暂知旧航路观测节点卷末前须重建通路，不允许靠主角直觉一步找到。

05

地形与气候环境

天气同时影响行动、物价和生活。

时段 / 环境实际变化人物行动影响社会与经济后果
霜月初 / 北风初起港内潮湿、外海风向趋稳但强度增大出海选择顺风时窗；登堤要防滑船期缩短容错，迟交货更容易赔钱。
霜月中后 / 山口冰路夜间结冰，驮道承重不变但行进减慢同样140里需要四日甚至更久煤价先涨，再影响修船和住屋取暖。
雨季 / 河流春汛水闸频繁调整，支渠漫溢河运速度不能按平水期计算粮仓先保高处存粮，低洼村户需转移。
大潮夜 / 港城低处下层栈桥没水、地砖返湿追逐路线减少，书库忙于搬纸停工与维护费用增加，穷人住所先受影响。
感官与生存

外海盐雾会让裸露皮肤刺痛；湿衣难干，轮班不换衣会冻伤。登山不只有风景，也需要鞋、火种和额外口粮。

怪异与正常区分

普通潮差先按自然周期理解。出现逆常识现象时，记录地点、时间和观察者，再考虑异常规则，不把所有困难解释成神秘力量。

06

资源与物产

资源在哪里，争夺和贸易就在哪里。

土地 → 港口
粮食与淡水

芦汀提供主粮；水车供城内日常用水。运输中断首先减少新鲜供应，再消耗存粮，不能一夜间所有人断食。

山地 → 船坞
煤与耐盐石

灰脊控制矿源，工匠在港城加工。原料与技术分布不同，因此双方都没有完全封锁对方的低成本选择。

群岛 → 航灯
油料与盐

群岛提供原料，港城炼制观测灯油；岛上也需买回成品。盐田丰收不等于岛民能吃饱或看病。

物产储存与加工运输制约冲突入口
谷物高堤仓储防潮，入港前复秤河闸和浅滩短秤可能是损耗，也可能有人挪用。
灯油密封罐、避火分库；旧油效能下降需要稳定船期重复签收意味着实物流向与账目不符。
耐盐石矿场初切、港内精磨重量大，驮道运费高不能靠一人背回足够修灯的材料。
07

势力分布

宣称、实际治理与可投送力量分别记录。

势力实际控制到场能力薄弱边界
港务署港内税门、公开码头与灯标内水域港内警力数刻可到；出海需征用船不会因签一张命令就瞬间抵达群岛。
潮灯会会馆、仓库、沿岸合法航灯依船期与值守队轮班能够护航不等于可以统治岛民。
矿联与关守矿区合同、主道货场与石门关主道集中，支路稀疏没有完全覆盖山地小聚落。
群岛联席锚地、集市和季节渔场依各岛小艇互通暴风时岛际联系也会中断。
黑帆帮部分暗港与走私泊点，非正式领土少量快船，靠情报挑弱点长期封锁会招致联合清剿，不能无限持续。
08

交通与通行

不仅有距离，还要有速度假设、费用和补给。

甲

白帆港 → 盐风群岛

沿三盏合法航灯出海。必须申报船期、携带备用灯油；遇北风绕南礁，不能直接穿越禁海。

2—3 日180 海里 · 帆船
乙

白帆港 → 芦汀粮仓

溯雾河经两处税闸。粮船可顺流半日抵港；逆流返程约一日，暴雨后停航，不按陆路速度计算。

半日 / 1日90 里 · 顺流 / 逆流
丙

白帆港 → 灰脊石门关

沿西北驮道行进，第二日晚必须在换马铺补水。霜月之后山口结冰，货重时至少多留一天。

3—4 日140 里 · 徒步驮队
时间口径

海程按普通货船平均 6 节、每日有效行航 15 小时估算，180 海里需约两日；逆风、检查和等待潮窗另计。港内传信约一刻，跨海消息至少随下一班船抵达。

路线口径与平均速度补给 / 费用替代方案与代价
港—群岛180海里；6节、每日有效15小时，约两日；等潮与逆风另计货船船铺通常按航次收费，饮水逐日定额；检查需看船籍绕南礁多约半日并增加灯油消耗，不能总比正路更快。
港—芦汀90里约45公里；顺流半日、逆流一日只是正常基准两处税闸，码头有热食和补水步行堤道约两日，不能用来运大宗谷物。
港—石门关140里约70公里；驮队日行20—25公里，正常三至四日第二夜换马铺补水；人和牲口都要口粮旧矿道近但陡，空身可走，满载矿料不得强行通过。
城市尺度另算

西巷到书库约三刻；会馆到东港约一刻；北堤近路可省一刻，但受涨潮和载重限制。跨区行程用日，城内行程用刻，不能混用同一张比例图。

09

危险区域与风险

风险有范围、预警和当地人的应对方式。

区域危险 / 预警规避与救援为什么仍有人进入
东北禁海公开禁航；潮图与普通磁针失配重建潮窗、设置返航界限；无法指望港内即刻救援旧灯证据、失踪亲属或不愿公开的交易。
石门冰坡夜间薄冰、马蹄频繁打滑白日行进，减载；救援需要本地熟路者矿工靠这条路领工钱，不能靠一句禁止就停止生活。
雾河低堤水位越过刻线、闸声异常先转移粮食与老幼，不逆流抢货住所和土地集中于此，迁移需要成本。
港北旧堤朽木、潮水漫过下级石阶辨潮位、避开载重追逐它是绕开税门和盘查的现实近路。
10

地域特色

风土不是标签，要能改变来客的行为。

灰脊与芦汀

矿镇建筑低厚，屋檐挂护灯铁罩；人们先问雇主再问姓名，因为劳动担保比社交更重要。平原居民习惯把水位刻痕记在门柱上，谈天气常是在讨论一家人的收成。

港城与群岛

港城用船期描述等待，码头茶棚最重要的商品是消息。群岛来客先看鞋底盐痕判断你走过哪片礁，敬客先给淡水而不是酒，因为水比热情更有成本。

可直接写入正文的场景
目标

沈砚第一次借宿岛民家

阻碍

他用港城习惯想付一夜房钱

行动

主人请他先说明船期和剩余饮水，他帮忙补写油料收据

代价与结果

交换从金钱变成共同承担断航风险；地域改变交往方式。

11

剧情作用

地理限制必须改变行动选择。

他能抄近路翻过北堤，却带不过那只怕潮的账箱。选择不是“哪条路更短”，而是“愿意丢掉什么”。
  • 走正门：要接受港务署检查，可能暴露账册。
  • 走北堤：早一刻到达，却必须有人背箱、有人探路。
  • 等退潮：最安全，但送信船会先离港。
写作约束

换地图必须同时改变通行规则、生活成本和信息速度。灰脊山始终在港口西北，群岛在外海东南；新增通道必须解释谁建、谁知情、谁维护。

12

写作约束

一处变化必须沿着连接关系传导。

  • 区域方位保持：山地西北、平原西部、港城中部沿海、群岛东南、禁海东北。
  • 不能让人物一夜完成地图上两日航程，除非解释船速、天气和实际代价。
  • 资源短缺先查库存与运输周期，不写所有地方同一刻突然饥荒。
  • 新道路要有建造、维护、知情者与载重限制；秘密通道不是免费传送。
  • 地方控制权变化影响税收、通行和补给，不只更换旗帜。
