# 妈妈·全身心付出型 - 表达特征与画面感

## 创作用途

本文件把她的说话方式、身体动作和可复用的画面固定下来，让每一场出场都能被读者记住。

## 句式习惯

- 长句为主，喜欢用逗号把句子串成三截：「你这几天是不是又没好好吃饭，脸色都这样了，我给你煮点面」。
- 叮嘱句用疑问句收尾，不用命令句：「带伞了吗」「吃了吗」「冷不冷」，问句让人不好拒绝。

她会怎么演

怎么说话

语速中等，句子偏长，一句话绕成三小句讲完——先说天气，再说衣，再说人。同一句叮嘱会在同一场戏里反复出现，每次添一个新细节：从「带伞了吗」变成「伞在你门后那把，蓝的那把」。

怎么想

  • 孩子的安危高于一切，她的排序里没有「我想吃什么」，只有「谁还没吃」。
  • 付出是天生责任，不需要被感谢——被道谢时反而摆手说「这算什么」。
  • 爱要落到具体物上，早饭、炸衣、寄钱，比一句「我爱你」更算数。
  • 最怕的不是累，是孩子不需要自己了。

怎么判断

  • 先安排子女的衣食住行，再谈自己的想法。
  • 用照顾和牺牲换取话语权，不用命令。
  • 反对一件事不明说，而是反复叹气、偷偷准备替代方案。
  • 发现孩子受苦时不顾一切，前提是给钱或给命。

什么不做

  • 不能把付出写成单纯的感动表演，每次牺牲都要有代价。
  • 不能把控制欲写成理所应当，要让读者看见孩子喘不过气的那一面。
  • 不能写成只会牺牲的空壳，她必须有自己的不甘。
标志性画面
这些画面每次出场都可以复用。
出场把最好的一口留给别人，自己总说不饿。
叮嘱从「带伞了吗」变成「伞在你门后那把，蓝的那把」。
挽留嘴上帮着看房子，回家却把那张床的床单洗好晒好。
收场夜里在手机上翻那件没买成的衣服，看着看着锁屏，第二天照常起早做饭。
诚实边界：仅作创作气质参考，不等同真人、不冒充、不替代人物小传，须服从大纲与情节因果。
