拆书库：旧版结果并入新版页签 — 实施计划

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox-style tracking.

Goal: 把旧版拆书结果按技能并入新版三个页签，去掉页面底部的独立旧版块，并迁移旧版挂载时承担的副作用。

Architecture: 给三个既有旧版展示组件加 variant="embedded"（隐藏管理类控件与重复标题），由新的薄封装 LegacySkillResults 按 activeSkill 渲染在新版结果下方；LegacyBookAnalysisView 停止挂载，它原先承担的 3 个副作用迁进工作台。

Tech Stack: React 19 + TypeScript + zustand + vitest + Playwright（仅用于真实浏览器几何检查）。

设计依据: docs/book-analysis-legacy-merge-20261006/spec.html

约定

  • 每次跑测试都带 --exclude '**/.codex-temp/**' --exclude '**/.claude/**' --exclude '**/.worktrees/**'，否则会误扫临时目录。
  • 不要与 npm run build:portable 并发跑 vitest。
  • 全量回归基线是 195 项既有失败（已用 git stash 对照确认）。多出来的失败一律视为自伤。
  • variant 默认值是 "full"，因此旧版页面行为与既有测试不变。

import { useState } from "react"
import type { AnalysisSkill } from "@/lib/novel/book-analysis/analysis-pipeline-types"
import type { BookAnalysisLibraryBook } from "@/lib/novel/book-analysis/library-state"
import { BookAnalysisCharacterPanel } from "./book-analysis-character-panel"
import { BookAnalysisStyleCard } from "./book-analysis-style-card"
import { StoryMapContent } from "./book-analysis-library-layout"

/**
 * 把旧版各技能的结果并进新版页签：只呈现结果，
 * 重新提取／启用／删除等管理操作不在这里出现。
 */
export function LegacySkillResults({ book, skill, storyMapRefreshKey = 0 }: {
  book: BookAnalysisLibraryBook
  skill: AnalysisSkill
  storyMapRefreshKey?: number
}) {
  // 角色选中状态放在这里持有，让 BookAnalysisCharacterPanel 保持受控。
  const [selectedCharacterId, setSelectedCharacterId] = useState<string | null>(null)
  return <div className="wb-legacy-results" data-testid="legacy-skill-results">
    <p className="wb-legacy-hint">旧版资料</p>
    {skill === "characters" && (
      <BookAnalysisCharacterPanel
        variant="embedded"
        book={book}
        selectedCharacterId={selectedCharacterId}
        onSelectCharacter={setSelectedCharacterId}
      />
    )}
    {skill === "story" && (
      <StoryMapContent variant="embedded" bookPath={book.path} refreshKey={storyMapRefreshKey} />
    )}
    {skill === "style" && <BookAnalysisStyleCard variant="embedded" book={book} />}
  </div>
}
