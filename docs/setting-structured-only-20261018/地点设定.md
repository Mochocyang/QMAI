# 霜河渡口（关卡）

雪线以南最后一个能补给人马的地方，过河之后就是没人管的四十里。

## 地点定位

- 所属区域：霜河北岸，南接三城官道，北通雪线河谷
- 类型：渡口兼换货市集
- 尺度：南北约二百步，东西约一百二十步，两岸各一处货棚
- 内部布局：南岸货栈、冻库、账房；北岸换货棚与马厩；中间一座浮桥
- 当前状态：封山前一月，商队排队过河，浮桥夜不落锁

## 所属势力

- 所有者：名义归三城共管，实际由青云商会出资维护
- 实际控制者：青云商会（南岸）与黑水帮（北岸换货）
- 常驻使用者：码头工、脚夫、过路商队、两处收税人
- 控制权变化的影响：北岸易手即可掐断雪线补给，南岸易手则三城冬季盐价翻倍

## 剧情作用

- 相遇：所有要进雪线的人都在桥头等放行，主角与老韩的第一次对话发生在这里。
- 交易：北岸棚外是唯一能在不进城的情况下换到雪线货的地方，代价是过货被记账。
- 冲突：桥面单向放行制造了「谁先过河」的争夺，一场雨夜排队足以写出三方角力。
