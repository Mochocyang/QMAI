7 项既有失败：模型／深度测试的调度器替身缺少 registerTask（6 项），缓存流程的调用次数预期不一致（1 项）。本轮没有修改这些业务模块。

构建仍有 pangu 的 Node 模块浏览器外置、混合动态／静态导入、大分块以及 Rust 未使用函数警告，未借本次 UI 改造扩大修复范围。
