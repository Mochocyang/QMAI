# 第一卷 · 雨夜无我

> 楚白为了还清欠老秦的三万七，接下一趟不该接的活，从此被卷进废品站背后的买卖。

## 故事1：雨夜里的货箱

- **章号范围：** 第 1–12 章
- **章情节拍：** 平升起紧落缓升紧顶缓顶悬

### 起① 常态与破口 · 雨里推车

- **人物：** 楚白、老秦
- 楚白在雨里推着满载的板车往废品站走，鞋里全是水。
- 老秦在门口等他，只说了一句「今晚这趟不能砸」。
- 楚白注意到货箱比平时沉，油布是新的。

### 起② 人物站定 · 第一次验货

- **人物：** 楚白
- 他按规矩敲箱，回声不对。
- 他掀开第一层油布，看见的不是废铁。
- 他把油布盖回去，没有告诉老秦。

## 故事2：竹哨

- **章号范围：** 第 13–24 章
- **章情节拍：** 平升起紧落缓升紧顶缓顶悬

### 起① 常态与破口 · 院墙外

- **人物：** 楚白、陌生人
- 竹哨在院墙外响了三声。
- 门外的人叫出了楚白的名字。
- 楚白第一次没有回头。
