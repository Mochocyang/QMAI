拆书失败根因与处理

实际问题处理方式
凡人草稿将词汇标为已覆盖，但没有对应规则覆盖状态由程序按规则计算；没有规则的维度明确标记不足，不制造规则，也不因模型声明错配重生成整份结果。
字段错误逐个暴露，唯一一次修订无法修完根字段、规则、词项、场景的结构问题统一收集反馈，附上字段/条目编号；修订仍有上限。
词项的证据ID指向不含该词的片段生成阶段模型只选原文连续词项及解释，程序逐字定位并回填真实引用；词项不存在仍失败。用途、可迁移性和具体性仍由独立核验检查。
长输出罗列大量编号，发生截断收紧JSON篇幅与请求输出预算，减少重复覆盖声明，要求只选关键引用。没有删除正文尾部，也不把截断输出当成功。
修订示例把场景对象误导为字符串按实际失败条目提供完整对象模板，保留通过项；不完整修订继续保存草稿，不强行入库。
核验对象编号错配每个R/W/S对象由程序显式绑定编号，修订复核只发送本次需检查对象。
角色Skill接口返回503、模型无可用通道明确中文提示选择可用服务，保留结果与草稿；角色/故事也统一使用短证据编号并反馈全部语义问题。

规则/场景仍校验有效引用；词项仍逐字核对且检查用途。不把无依据结果自动加入使用库，不自动绑定人物或启用文风。算法缓存已升级，旧文件和绑定保持不变。

已通过区块的可用规则（第1～10章，待人工确认）

小说采用第三人称有限视角，聚焦主角内心独白与外部行动，句法长短句交替多逗号分句，对白插入动作如“恩！”“啪嗒”，词汇高频门派术语与人名，描写环境感官细节，节奏段落呼吸切换，整体沉浸式日常语感。

仅基于10章21575字样本，聚焦入门章节，未覆盖全书后续；高频词统计仅描述现象，不代表作者偏好；样本规模有限，无法覆盖全书风格。 自动修订已移除4项未通过核验的内容，仅保留有依据的规则；未观察到的习惯仍未知，使用前需人工确认。

R1 · register

适用：人物对话与互动场景

在对白中添加动作描述增强互动，同时区分角色正式与口语表达，分声处理

边界：单一角色俏皮话仅局部，不要求全体配角统一

R2 · lexicon

适用：叙述与对白中

使用主角姓名与门派术语标识叙述焦点，搭配日常词汇营造世界感，区分叙述者与角色

边界：仅记录连续出现词项，不拼接模板或省略号

R3 · syntax

适用：叙述段落

长短句交替使用，逗号连接多重信息，保持叙述流畅性

边界：非一律短句，允许分句顺序灵活

R4 · narration

适用：人物内心与行动场景

通过内心独白揭示想法，外部行动推进情节，评述适度出现

边界：人物价值观不等作者文风

R5 · dialogue

适用：对话互动场景

使用动作如‘笑眯眯’‘冷哼’分角色声，口语表达增强生动

边界：现代词汇仅核实出现处，不限定所有配角

R6 · description

适用：场景转换与内心

详细描述物理环境与人物感官反应，避免直接情绪词

边界：不冒充生动细腻描写

R7 · rhythm

适用：段落间衔接

控制段落长度，快慢切换，铺垫留白，信息先后投放

边界：长段占比低，保持呼吸感

R8 · structure

适用：多场景转换

用时间推进或人物移动衔接场景，信息分批投放

边界：不改写剧情机制为固定文风

未采纳记录（模型核验意见）

弟子：词项“弟子”在原文中被大量用于门派成员称呼并区分正式与记名弟子（如E26、E27、E30），用法具体且有样本支持；但区分正式/记名弟子的用法直接源于原作门派设定与剧情顺序，不可迁移为通用写作习惯。

恩：词项“恩”作为对话回应动作出现在原文中，但其用法直接体现角色乖巧性格（如E54、E59、E99）；按指令“不要把角色性格当作者写法”，此非作者写作风格，故不支持。

山崖攀爬区：场景“山崖攀爬区”为通用类别，但guidance“描述爬山辛苦节奏”直接规定原作具体剧情顺序（E109、E116、E131），portable必须false。

药谷隐秘处：场景“药谷隐秘处”为通用类别，但guidance“环境描写与互动揭示世界观”直接规定原作具体剧情顺序与设定（E170、E172、E162），portable必须false。
