“陈禾，还不走？都六点多了。”周叔站在门口，手里拎着一串钥匙，金属碰得叮当响。他往屋里扫了一眼，见她还趴在桌上，便又催了一句，“明天再弄吧，闭馆了。”

陈禾抬起头，笑了笑：“周叔，您先巡您的，我把这点对完就走。”

周叔没再说什么，钥匙串晃了晃，人已经往东边去了。脚步声渐渐远了，修复室里只剩空调低低的嗡鸣。

她又低下头，把封签和归档单并排放在白纸上，拿手机拍了张照。日期差一天，说大不大，说小也不小。她没打算现在就去找谁问，更没想过要指认是谁填错了——博物馆里经手的人多，流转环节也多，贸然开口，反倒容易让人下不来台。她只是把照片存进工作文件夹，又在登记簿的备注栏里用铅笔轻轻画了个圈。

窗外天色暗下来，玻璃上映出她自己的影子，模模糊糊的，和身后一排排铁皮柜叠在一起。她收拾好桌面，把地图重新锁进恒温柜，钥匙转了两圈，咔嗒一声。

就在这时候，储藏室那边传来一记闷响。

咚。

很轻，像什么东西从架子上滑下来，又像有人用指节在木板上敲了一下。陈禾停住脚步，侧耳听了一阵。空调还在响，走廊的灯管偶尔滋滋闪一下，别的什么动静也没有。

她心里有些犯疑，却也没慌。这栋楼老，管道热胀冷缩，夜里常有些响动。她关了修复室的灯，带上门，往储藏室方向走了几步。走廊尽头的安全出口指示灯绿幽幽地亮着，照出一小片地面。

咚。

又是一下。这回她听清了，是从储藏室里面传出来的。
