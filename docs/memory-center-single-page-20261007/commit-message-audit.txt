脚本本身修掉两个会让扫描变成"假安全"的缺陷：
- 第一版用 `git show HEAD:<path>` 逐个读文件，中文路径需要处理 Git 的
  C 风格引号转义，于是 skills/soulskill/**、tests/fixtures/** 里的中文资料
  全被静默跳过 —— 报"扫了 2518 个文件"，其实有一批根本没读到。
  改用 git grep（在对象库内部匹配，不受 shell 与路径转义影响）。
- 加豁免名单但要求逐条写明理由、且必须是**精确串**而非正则；
  同时要求每条豁免都仍然在仓库里命中，否则报 FAIL ——
  没有这条，豁免名单会随代码演进变成"永久免检"。
