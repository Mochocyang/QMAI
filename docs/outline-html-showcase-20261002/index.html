02

这套示例想解决什么

不靠不断增加边框和颜色制造“美化”。

01

内容决定版式

地图、预算、成长阶梯和线索链各有自己的形状，不把所有信息压进同一种卡片。

02

详细，但不拥挤

先给读者总览，再进入解释；保留长正文的阅读宽度，让重要规则和风险更容易找到。

03

像一本设定集

暖纸色、深墨蓝、铜金细线与中文衬线标题。少用装饰性图标，让图形真正承担信息。

03

你可以怎样反馈

先判断方向，不需要一次讨论所有字段。

先看地理
地图位置、区域说明、路线层级和整页气质，是否比之前更符合你的期待？
再看差异
人物、组织、力量体系是否各有适合自己的结构，而不是同一张表换标题？
指出具体位置
可以直接说“地理第二部分太密”“喜欢组织收支这块”“标题太大”，也可以给截图。
确认后的边界
只有你认可示例并明确同意接入，才修改软件源码与模板。现在不提交、不合并、不替换原文件。
