# QMAI 4.3.1 更新内容清单

> **对比基线**：v4.2.0（2026-10-09，标签 `v4.2.0`）→ v4.3.1（2026-10-12）
> **本文件用途**：可对外发布的更新日志。分节可直接作为 GitHub Release 正文使用。
> **规模**：期间共 **268 个非合并提交**（另有 8 个分支合并），其中 96 个是文档、
> 13 个是测试补充、6 个是杂项 —— 这些不影响使用，归在附录。
> **核对说明**：正文每条来自提交标题与本次会话的实测；4.2.0 那版逐条回源码复算过，
> 本版因提交量是上一版的 3 倍，**未逐条回源码复算**，如需逐条核对请对照附录的提交号。

## 更新概览

这一版的主题是**「把细纲、人物、文风三条线都接进真正的写作现场」**：

- **事件细纲**：从「能聊」做到「能落到章节」——向导、事件卡片、正文生成、保存闸门整条链打通；
- **人物 Skill**：新增整个能力域，读章节学人物，学完能注入写作；
- **文风**：能选、能引用、能建，本轮又把入口收干净；
- **续写 / 拆书库 / 共创 / 舞台情景**：四条既有线各自补齐；
- **修复**：备份导出导入 9 项缺陷、弹窗被压成全屏、侧栏菜单被裁切等。

---

## 一、事件细纲：从「能聊」到「能落到章节」

1. 【新增生成章节细纲向导】在对话里按步骤生成一份轻量章细纲（约 4~8 个事件）
2. 【新增只读事件卡片与扩写入口】细纲以卡片呈现，可从卡片直接扩写
3. 【从 AI 回复解析事件细纲数据】回复里的结构化数据能被解析出来，不再是纯文本
4. 【新增下一章章号探测】自动判断下一章是第几章；只看章节库，避免章纲与笔记顶飞章号；不再把目录名里的数字当成章号
5. 【新增事件细纲契约、归一化与校验】补齐目标字数校验；软性字数提示**不再阻断**扩写
6. 【独立的保存类型与文件夹】注册 `event-outline` 保存类型、内容闸门与「事件细纲」文件夹；细纲**不再落进**章纲文件夹，也不再存进大纲列表
7. 【入口搬进章节区】生成入口从大纲面板移到章节区，删除向导死链
8. 【确认后直接生成章节正文】细纲确认后在章节区直接产出正文；正文落盘统一走一个写入函数
9. 【卡片支持手动修改与 AI 重新生成】改完可让 AI 重生成，且**带上你手改的要求**与**手改的目标字数**
10. 【交接时展开写作面并保留已有草稿】细纲交接到章节时不覆盖已有内容
11. 【首次进入对话的分步引导教程】第一次打开细纲对话有引导
12. 【空章节灵感气泡】空章节在「生成章节细纲」按钮旁挂出灵感气泡，可在写作设置里开关
13. 【取消与重入不再出错】同章重提会中止被取代的那次生成；取消后立即清掉控制器；重入时旧一次的收尾不会摘掉新一次的取消句柄；取消不再是空操作，也不再跨项目写入或产生同章重复文件
14. 【提示词加固】逐个对象重扫围栏，避免漏解析与自相矛盾；扩写接回你对本章的要求

## 二、人物 Skill（新增能力域）

15. 【新增人物 Skill 页与草稿守卫】独立页面，未保存的草稿不会被静默丢弃
16. 【独立存储层】人物 Skill 有自己的存储；坏索引不再被静默抹掉
17. 【提取记忆时后台学习】读章节记忆的同时在后台学人物
18. 【章节学习编排】按章节编排学习任务
19. 【研究文件】为每个人物生成研究文件，且**只在首次生成**，不重复写
20. 【分级注入】按档位决定注入多少，不再是全量硬塞
21. 【写作上下文注入】人物 Skill 真正进入写作提示词
22. 【单次多人物提示词】一次可带多个人物
23. 【类型阈值与档位判定】按类型阈值决定人物档位
24. 【字段表对齐为 5 个「演技」字段】
25. 【修「提取了记忆但技能库里没有人物」】此前是静默失效，没有任何提示
26. 【修「提取完了技能库还是空的」】解析器比真实模型严格，且每条偏离路径都静默——现在能落地
27. 【学习完成后给出提示】学完会弹窗告知，不再无声结束
28. 【并发保存不丢手改正文】并发写入时保住你手改的内容，出场记账确定性落盘
29. 【保存加锁】把用户保存档案也收进同一把锁
30. 【非绿勾人物不得重新整理研究文件】

## 三、文风

31. 【技能库新增「文风」tab】以引用方式列出项目里的文风预设
32. 【生成时可选「文风写作」】只对这一次生成生效，**不改动项目设置**；切换项目时临时选择会重置
33. 【输入框 @ 文风引用真正接入】在消息里 `@` 一条文风，会真正覆盖本次生成
34. 【文风 skill 编辑器】可以直接编辑文风 skill
35. 【文风自进化】自动分析已写章节，提取写作与用词习惯形成文风
36. 【本轮收口：下拉只剩两项】打开文风选择器只剩「当前文风」与「打开文风库」——
    「跟随项目设置的文风」「本次不用文风」已移除，**启用与停用统一在文风库里做**
37. 【本轮收口：自进化开关改造】开关改为「文字在左（已开启 / 已关闭）、滑块在右」，
    与大模型页那枚开关一致；说明文字改为讲清「会分析已写章节、会消耗 token、
    结果需要你点一下才启用」
38. 【本轮收口：文风库新增「去拆书库添加文风」】文风的正经来源是拆书库的提取，
    「新建文风」只能建空壳，现在两个入口并排

## 四、角色灵魂与故事 skill

39. 【输入框 @ 引用角色灵魂并真绑定到小说人物】引用不再只是文本，会绑定到具体人物
40. 【按快照完整还原绑定】含 aliases，还原后不再缺项
41. 【拆书发布桥接修正】桥到 `storyFrameworkBinding` 真正读的那个存储，不再是读一份写另一份

44. 【生成、流式显示与插入写回】结果流式显示并写回正文

## 六、拆书库
