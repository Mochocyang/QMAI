# 卷纲折叠树（10 个故事 × 10 个环节）

## 触发与适用范围

- 适用于：用户要求生成某卷的卷纲、分卷大纲、卷一大纲，或要求按「10 个故事 / 折叠树 / 十环节」结构整理卷级大纲。
- 不适用于：章纲、总纲（全书大纲）、人物小传、设定、伏笔、正文。

## 卷纲定义

1 个卷纲 = **10 个小故事**。每个小故事固定跑满 **10 个环节**（起3 + 承3 + 转2 + 合2），约 12 章。10 个故事靠「引线」首尾咬合。生成前应读取项目大纲目录下已有的总纲、人物小传、设定、伏笔文件作为素材，确保人物与设定自洽。

## 只写故事，不写台账

卷纲只回答一件事：**这卷发生了哪些故事，每个故事怎么一步步推进**。写小说的人拿它去写正文，不会去看统计表。

**禁止输出**（软件不显示，只会白烧 token）：

- 卷级定位：卷定位 / 主题句 / 叙事形态 / 结构选用声明 / 建议章数 / 卷末落点；
- 人物出场表、地点组织索引、伏笔追踪表、悬念债务表、对手推进表、人物成长与资源表；
- 整卷账本、三层线配比、期待感强度曲线、反转类型分布、支线推进矩阵、节拍体检、环节完整性矩阵；
- 任何评分、覆盖率、体检结论、方法论说明板块。

## 10 环节体系（遵循即可，不要输出到界面）

| 环节 | 要完成什么 |
|---|---|
| 起① 常态与破口 | 先立「正常」，再用异常捅破 |
| 起② 人物站定 | 新增人物一次交代清楚 |
| 起③ 目标与代价 | 把好奇升级成「必须」 |
| 承① 尝试与失败 | 旧方法解决问题 → 失败 |
| 承② 资源拼图 | 攒信息 / 物件 / 人情 / 规则 |
| 承③ 中点反转 | 换掉问题的「性质」 |
| 转① 认知反转 | 换掉一个前提（不是多一个帮手） |
| 转② 代价抉择 | 付出一样东西换取前进资格 |
| 合① 小高潮 | 结账：表层矛盾解决、代价落地 |
| 合② 引线与余震 | 未解之物 + 状态改变 + 下故事钩子 |

## 输出规格

**只产出两部分，不要写 MD 正文**（MD 与 HTML 都由软件从数据生成，重复写等于让用户多付一倍钱）：

1. 一个 ```json 围栏，顶层字段 `volumeOutlineData`；
2. 一个 `outlineSaveRequest`（`content` 写空字符串 `""`）。

```json
{
  "volumeOutlineData": {
    "title": "卷一 卷名",
    "goal": "本卷一句话目标",
    "stories": [
      {
        "id": 1,
        "range": "第 1–12 章",
        "title": "故事一标题",
        "beats": "平升起紧落缓升紧顶缓顶悬",
        "st": [
          { "stage": "起①", "label": "雨夜的电话", "who": "杨寒（主角）＋ 姑姑（常态锚点）", "p": ["事件1", "事件2", "事件3"] },
          { "stage": "起②", "label": "守夜人", "who": "陈守拙（引路）＋ 主管（阻力）", "p": ["事件1", "事件2", "事件3"] }
        ]
      }
    ]
  }
}
```

**字段说明**：

- `stories` 必须 10 个；每个故事只有 `id` / `range` / `title` / `st`（可选 `beats`）。
- `st` 必须 10 条（起①~合② 全覆盖）；每条只有 `stage` / `label` / `who` / `p`。
- `p` 必须 3 条，且必须是**这一步里具体发生了什么**（事件、动作、决定、代价、说出口的话），不要「铺垫矛盾」「承上启下」这类空话。
- `beats` 是 12 个字符的节拍序列（平 升 起 落 缓 紧 顶 悬），章纲要靠它对齐，能写就写。
- 上面示例只展示 2 个环节（**10 个环节必须全部写满，一个都不能少**）。

### 保存请求

```json
{
  "outlineSaveRequest": {
    "targetFolder": "卷纲",
    "fileName": "卷纲-第XX卷.md",
    "fileType": "volume-outline",
    "writeMode": "create",
    "referencedSkills": ["DagangSkill/juangangzhedieshu"],
    "sourceIntent": "生成第XX卷卷纲",
    "content": ""
  }
}
```

**不需要**提供 `htmlContent`（软件套模板渲染折叠树），也**不需要**在 `content` 里重写一遍正文。

## 输出顺序

1. ```json 围栏的 `volumeOutlineData`（10 故事 × 10 环节全写满）；
2. `outlineSaveRequest`。

## 常见错误

- 故事不足 10 个，或用「…」跳过中间故事。
- 环节不足 10 个，或每环节内容不足 3 条。
- 每环节内容写成「铺垫 / 推进 / 收束」这类空话，而不是具体事件。
- 又补了一大段 MD 正文或台账表格（白烧 token，软件不使用）。
- 自己手写 HTML/CSS/标签。
