# 设定信息标准

## 使用范围

本标准用于 AI 大纲会话生成、补全、改写小说设定文件。设定文件不是背景资料堆砌，而是后续章纲、人物和正文共同读取的规则约束库。

设定必须回答四件事：

1. 这个设定是什么。
2. 它如何影响人物行动。
3. 它如何制造冲突、爽点、悬念或情绪。
4. 它在写作时有哪些边界，哪些内容不能乱写。


项目规模小时可以合并文件；设定一旦影响多章正文，必须独立成文件。

## 设定类型

| 类型 | 默认文件 | 重点 |
|---|---|---|
| 题材定位 | `设定/题材定位.md` | 题材类型、核心梗、目标读者、卖点、风险 |
| 世界背景 | `设定/世界观/背景设定.md` | 世界差异、社会环境、时代背景、核心舞台 |
| 世界规则 | `设定/世界观/规则体系.md` | 规则来源、边界、代价、信息公开度、反制方式 |
| 力量体系 | `设定/世界观/力量体系.md` | 等级、能力、晋升、消耗、克制、代价 |
| 金手指 | `设定/世界观/金手指.md` | 绑定方式、任务机制、奖励、限制、使用边界 |
| 势力组织 | `设定/势力/{势力名}.md` | 目标、资源、内部矛盾、代表人物、主角关系 |
| 地图场景 | `设定/地图/{地图名}.md` | 环境规则、资源、危险、出入条件、阶段作用 |
| 道具物件 | `设定/道具/{道具名}.md` | 来源、用途、限制、归属、后续回收 |
| 伏笔悬念 | `追踪/伏笔.md` | 埋设、推进、提示、回收、后果 |
| 时间线 | `追踪/时间线.md` | 故事时间、事件顺序、并行线、疑点 |

## 背景设定详细内容契约

每个对象必须按顺序覆盖以下 12 个分区；逐条落实字段，不将一整区压缩成一句概述。

### 1. 世界观背景

时代、世界尺度、文明分布、核心舞台、普通人生活状态与核心矛盾；交代世界靠什么生产和维持秩序、当下为什么不稳定，以及主角进入世界时面对的现实问题，而非只给恢宏历史简介。

载体：kv；按上面的要求拆分具体字段和条目。

### 2. 世界前提与差异

写与现实或同题材常规世界不同的关键前提、形成原因及连锁后果；逐条落实到资源、生产、战争、家庭、交通与信息传播。特殊现象要有边界、成本和受益受损者，不只是装饰性奇观。

载体：kv；按上面的要求拆分具体字段和条目。

### 3. 时代风貌

技术及生产力、能源、农工商业、货币与交易、物价层级与收入、交通通信速度、医疗与卫生、城市和乡村日常；选取吃住行、生病、求职等生活场景说明时代规则，估算数值标注依据和口径。

载体：kv；按上面的要求拆分具体字段和条目。

### 4. 社会结构

写政权合法性、行政税赋、司法执法、财产继承、教育与知识垄断、职业和身份流动、家庭婚姻、弱势群体和救济；说明不同阶层如何谋生、获得保护或遭受剥夺，以及制度如何约束主角行动。

载体：table；表头：阶层或制度 / 权力与资源 / 义务与生计 / 流动与排斥 / 冲突及影响。

### 5. 文化习俗

覆盖适用的信仰、祭祀、节庆、饮食、婚丧、礼仪、审美和禁忌；写谁遵守、为何遵守、地区阶层差异和例外成本，给出可直接使用的场景细节，不把一种习俗无差别套给所有居民。

载体：table；表头：习俗与适用群体 / 历史或信仰来源 / 具体做法 / 利益和社会意义 / 违背后果及例外。

### 6. 语言与称谓

说明通用语、方言、书面语、官方和行业称谓、度量衡、纪年与时间表达；给出合乎身份的称呼示例，标注误称的后果、翻译或信息障碍，避免现代术语无解释混入或称谓前后漂移。

载体：table；表头：词语或称谓 / 使用者与场合 / 含义及权力关系 / 示例与禁用条件。

### 7. 历史沿革

按适用的起源、关键转折到当下说明因果链；区分史实、官方叙事、民间传说和待揭真相。每段历史至少解释一种当下制度、资源格局、敌对或禁忌，不为了分期数量编造无用年代。

载体：table；表头：时期与可靠性 / 事件及参与者 / 原因与代价 / 制度或地理变化 / 遗留矛盾。

### 8. 核心设定规则

分别交代自然、超凡或技术规则与人为法律，写能做和不能做、谁执行、如何发现违规、违反后果和已知例外；规则应可在情境中验证，解释为何强者、政权或技术不能绕过所有矛盾。

载体：table；表头：规则及适用范围 / 原理与边界 / 触发和代价 / 例外及验证方式 / 社会后果。

### 9. 信息公开度

区分作者层真相、读者已知、主角所知、配角和反派认知，写谎言与误解的传播者和获益者；重要信息注明渠道、时点及可靠性，未知保留，不能让角色使用尚未获知的世界设定。

载体：table；表头：事实或秘密 / 知情者与认知 / 公众说法 / 获知渠道与证据 / 揭示条件及后果。

### 10. 势力格局

解释主要权力中心、资源产销、贸易依赖、武力与合法性如何相互制衡；写公开秩序和地下秩序、边缘群体处境及近期导火索，与组织和地理设定使用同名同边界，避免重复造出冲突版本。

载体：table；表头：势力及控制范围 / 核心利益与资源 / 盟友及敌对 / 制衡与依赖 / 当前变局。

### 11. 剧情作用

将背景转成可触发的困难、机会、道德选择与信息差，说明涉及人物、现实代价、读者如何通过行动逐步理解；至少给出日常与重大冲突两种使用情境，不以百科介绍替代小说场景。

载体：list；按上面的要求拆分具体字段和条目。

### 12. 写作约束

锁定纪年、技术上限、物价口径、通信交通、阶层和法律的一致性；列可变与不可变条件、规则揭示顺序及新增设定影响。避免后设救场、时代错位和无成本制度变化，待确认项注明影响与解决途径。

载体：list；按上面的要求拆分具体字段和条目。

### 结构化与保存

同时输出完整 MD 与 JSON。单对象顶层字段 `backgroundProfileData`，多个对象用 `backgroundProfiles` 数组；每个对象为 `{name,tag,tagline,sections}`，section 使用 `{kind,heading,items}`（kv 的 items 为 label/text 对象，list 为字符串）或 `{kind:"table",heading,head,rows}`。各分区标题、顺序及内容必须与 MD 等价，不得缩成摘要。

软件套用 `world-rules/background.html`，不要自行输出 HTML/CSS。最后按既有 outlineSaveRequest 协议输出保存请求，只有用户确认后才落盘。

## 力量体系详细内容契约

每个对象必须按顺序覆盖以下 13 个分区；逐条落实字段，不将一整区压缩成一句概述。

### 1. 体系概览

力量本质、来源、适用群体、获取门槛、在世界中的普及率、普通人的处境、总体上限和无法做到的事；说明力量与身体、精神、技术或环境的关系，以及它为何没有消灭现有社会矛盾。

载体：kv；按上面的要求拆分具体字段和条目。

### 2. 等级阶梯

从低到高逐级写完整：速度、范围、持续时间、防御或影响规模中适合本题材的实战标尺，同级差异、跨级差距、代表对手和破坏上限；非数值体系用明确情境标尺。不能只写强弱形容词或遗漏中间等级。

载体：table；表头：等级与定位 / 可观察能力及实战尺度 / 不能做到什么 / 突破门槛 / 稀缺度与社会地位。

### 3. 晋升机制

交代天赋、知识、训练、材料、环境和导师条件；区分达到门槛与真正突破，写平均耗时及个体差异、失败概率的依据和后果、恢复途径。捷径必须有不可忽略的成本，不允许为主角临时取消门槛。

载体：table；表头：阶段与条件 / 训练及验证 / 资源与耗时 / 失败及恢复 / 捷径与代价。

### 4. 能力分类

覆盖本体系适用的攻击、防御、侦察、移动、治疗或生产分支；说明原理、学习条件、兼修冲突、组合收益、替代方案及代表人物。不同分支应改变战术或生活方式，而非换名称的同一种招式。

载体：table；表头：分支与原理 / 用途和典型能力 / 适用场景 / 短板与组合 / 代表使用者。

### 5. 资源与消耗

明确一次使用、持续作战和长期修炼分别消耗什么，储存衰减、恢复速度、替代材料、产地和运输、资源垄断与定价逻辑；给出代表性持续行动场景的资源账，解释强者为何不能无限施法。

载体：table；表头：资源及用途 / 产地与供应者 / 获取成本与垄断 / 消耗和恢复 / 短缺后果。

### 6. 代价与限制

列身体、寿命、精神、记忆、社会身份或环境方面的真实成本；说明可恢复与不可逆部分、消耗阈值和透支后果。限制必须在剧情中生效，不能每次靠新道具抹除；指出绝对不能实现的效果。

载体：table；表头：能力或限制 / 触发条件 / 即时代价 / 累积后果 / 缓解方式与剩余代价。

### 7. 克制与反制

写信息、距离、地形、准备时间、材料和团队协作如何影响胜负；明确低阶越级必须满足的条件、失败风险和不可跨越的差距，反制要能被敌人使用，避免主角专属例外或绝对无敌属性。

载体：table；表头：对抗双方 / 克制原理 / 生效条件 / 反制及代价 / 越级边界。

### 8. 禁忌与风险

说明禁术、过载、污染、侵蚀、实验或非法传播为什么被禁止，诱惑是什么、怎样出现预兆、谁受害、谁监管及如何处置；记录遗留伤害和责任，不让禁忌成为无成本提升实力的捷径。

载体：table；表头：禁忌行为 / 诱因与预警 / 失控后果 / 处置和恢复 / 监管者。

### 9. 流派与势力

写知识传承、保密与垄断、教育成本、学徒待遇、流派资源和政治关系；说明力量如何影响生产、战争、司法和普通人的职业选择，以及流派差异如何形成真实利益冲突而非只换招式名称。

载体：table；表头：流派及理念 / 传承与招收 / 据点和资源 / 利益及竞争 / 代表人物。

### 10. 体系漏洞

仅设计符合既有规则的组合利用、认知盲点或制度漏洞，写发现线索、实施条件、收益、代价、敌人复制可能与修补办法。若体系没有已知漏洞明确说明，不能临时发明绕过所有限制的万能漏洞。

载体：kv；按上面的要求拆分具体字段和条目。

### 11. 成长节奏

与已有卷纲章纲对齐等级和节奏，区分力量增长、技巧熟练与认知提升；写每次突破前的铺垫、过程验证、代价和随之而来的更高层冲突。没有确定章号时用阶段，不虚构已完成的升级记录。

载体：table；表头：卷次或阶段 / 起点与目标 / 能力验证事件 / 资源和代价 / 新问题与伏笔。

### 12. 剧情作用

说明力量如何制造而非消除矛盾：具体的战术选择、资源争夺、身份变化、团队依赖和情绪回报；至少给出适用的典型冲突及行动后果，战斗胜负必须可从已建立的条件推导。

载体：list；按上面的要求拆分具体字段和条目。

### 13. 写作约束

检查等级标尺、消耗恢复、距离耗时、晋升条件和能力知识来源；区分角色理解与世界真实规则。禁止数值膨胀、临时加规则、突破抹平伤病或低阶能力凭空消失，记录规则增量及影响范围。

载体：list；按上面的要求拆分具体字段和条目。

## 金手指设定详细内容契约

每个对象必须按顺序覆盖以下 12 个分区；逐条落实字段，不将一整区压缩成一句概述。

### 1. 能力概述

金手指的来源、载体、独特优势、与世界力量体系的关系、服务的主角缺口及核心上限；明确能提供什么、不能替主角完成什么，系统或非系统类都必须可解释，不能把信息优势等同于自动胜利。

载体：kv；按上面的要求拆分具体字段和条目。

### 2. 获取与绑定

获取事件、选择主角的原因或待揭秘密、绑定对象、激活条件、初始权限、失败与解除绑定、可否转移继承、损毁或被夺取；写获取时付出的代价和世界内可观察的痕迹，秘密来源不得被角色提前知道。

载体：kv；按上面的要求拆分具体字段和条目。

### 3. 机制与规则

输入—触发—处理—输出的完整流程，作用距离、对象、持续时间、消耗、冷却和信息可信度；任务、奖励、兑换或提示只在适用时展开。说明错误、延迟、拒绝及反馈可见范围，给一个完整使用示例。

载体：kv；按上面的要求拆分具体字段和条目。

### 4. 已解锁能力

逐项写当前可用、受限、封锁的能力及对应章节或阶段，明确激活、输入、输出、限制和资源成本；未写到的能力标为计划解锁，不把未来奖励当现有资源。每项都应能指导具体行动。

载体：table；表头：能力与当前状态 / 来源或解锁时点 / 触发及效果 / 消耗与边界 / 证据或计划。

### 5. 能力分支与升级树

交代升级依赖、分支选择、机会成本、互斥关系、资源来源和收益递减；说明升级为什么会带来新风险或新责任，主角如何以自主选择而非被动领奖决定成长，不能所有分支无成本同时获得。

载体：table；表头：分支与目标 / 前置与取舍 / 解锁资源及事件 / 收益与新增限制 / 不可兼得项。

## 伏笔计划详细内容契约

每个对象必须按顺序覆盖以下 12 个分区；逐条落实字段，不将一整区压缩成一句概述。

### 1. 伏笔总览

标出核心悬念、对应主题、主支线、故事时点、计划与已发生的范围；数量必须来自实际列出的伏笔，不凑统计。说明读者当前会问什么、角色正在追查什么、最终真相为何值得等待及其情绪回报。

载体：kv；按上面的要求拆分具体字段和条目。

### 2. 埋设与回收节奏

按已确认的卷纲章纲规划首次埋设、再次强化、部分揭示与最终回收，避免集中讲解或长期失联；明确计划与已发生状态，写每步承担的当前剧情功能，未确定章号用阶段与触发条件。

载体：table；表头：阶段或章节 / 埋设与强化 / 误导或进展 / 回收与兑现 / 证据和记录性质。

### 3. 伏笔状态表

每条伏笔使用稳定ID，列可观察的原始细节、真正指向、关联人物和现有证据、计划节点、实际节点及当前状态；证据不足不能标已埋或已回收，无既有正文时全部采用计划状态，禁止虚构回收记录。

载体：table；表头：稳定ID与内容 / 表层呈现与真相 / 埋设位置及证据 / 回收条件和阶段 / 状态及重要度。

### 4. 线索链

设计能被发现、误读、验证和连接的证据链；写目击、物证、对白或规则异常的载体、可靠性、保存与传播方式、谁知道及何时知道。强化要增加信息而非重复，最终结论必须可从前文证据追溯。

载体：table；表头：线索与关联ID / 出现方式及载体 / 知情者与获知渠道 / 可推导信息 / 下一步验证及障碍。

### 5. 表层误导与真相

误导必须来自有限视角、人物谎言或合理巧合，不靠作者隐瞒视角人物已知事实；写错误解释为何可信、真相如何兼容前文细节、推翻误解需要什么证据以及相关人物承担的后果。

载体：table；表头：伏笔ID / 合理表层解释 / 误导来源及动机 / 真实因果 / 识破证据和后果。

### 6. 回收日志

只把正文或已确认材料中已发生的兑现写为回收日志；尚未回收时明确暂无已发生记录并列计划。回收要改变行动、关系、资源或主题理解，不能用一句解释了结，也不能把计划自动变成已完成。

载体：table；表头：ID与实际时点 / 揭示事件及证据 / 人物行动或选择 / 关系和局势后果 / 残余问题。

### 7. 过期与风险

载体：table；表头：ID及风险 / 现有症状与原因 / 补救或放弃方案 / 前置条件与影响 / 处理状态。

### 8. 关联人物

### 9. 关联设定与主线

载体：table；表头：设定或主线节点 / 关联伏笔ID / 因果及先后依赖 / 揭示后的改变 / 一致性约束。

载体：table；表头：悬念与读者问题 / 级别及跨度 / 维持与强化手法 / 阶段回报 / 最终兑现条件。

### 11. 剧情作用

载体：list；按上面的要求拆分具体字段和条目。

## 生成规则

1. 设定必须写清“运行规则”和“写作约束”，不能只写背景介绍。
2. 新增设定必须服务主线、冲突、情绪、伏笔或人物变化。
3. 补完已有设定时尊重已确认事实；新建设定应提供具体的【设计提案】，关键未知标为【待确认】并说明影响，不能用整页空项敷衍，也不能伪造已确认事实。
4. 影响多章的设定必须有更新记录。
5. 金手指和力量体系必须写限制、代价和反制点，防止万能化。
6. 势力必须有目标、资源和代表人物，不能只是名字。
7. 地图变化必须改变行动规则、资源和压力，不能只是换地名。
8. 伏笔必须有生命周期：埋设、推进、提示、回收、后果。
9. 题材定位必须写清读者承诺，后续大纲、章纲、正文不得偏离核心卖点。

## 详细设定共同质量要求

第二版详细档案标准：不是展示简介。基本身份、生活与供给、运行机制、权限与例外、失败后果、当前时点、知情范围、关联对象及写作场景均须具体；每个重要机制给出可核验的条件和后果，而非只增加段落数量。
数值闭合：组织收入、成本、利润、分配与现金流分开；人员分组与总人数吻合；同一行程的距离、速度、有效行进时长和等待时间一致；人物的收入、生活费、债务与储蓄互相成立。缺少依据时给明确假设，不硬凑精确数字。
同一事实只设一个当前基准：说明章节或时点，将未来升级、人物出场、伏笔回收与当前状态分开。跨人物、组织、地图、地点、卷纲和章纲的名称、时间、位置与证据应能相互核对。关联对象写名称和作用，不自行捏造文件路径或链接。
完整不是堆字数：覆盖本类全部分区与关键字段。重要对象逐项写清对象、机制、条件、代价、变化及正文用法，不能只列名词或写一句空泛评价；同一信息不反复复制充数。
区分【已确认】【设计提案】【待确认】。新建设定允许基于题材和已有材料提出具体、内部一致的设计，不用整页待补充敷衍；补完已有设定不得改写正史。关键未知写清问题、影响与可选设计，不能编造成已确认事实。
记录必须区分【计划】与【已发生】，注明章节或时点及依据；没有正文证据不得虚构出场、解锁、埋设或回收记录。无明确章号用阶段，作者真相不得越过人物认知边界。
按题材适配：非营利组织解释收支平衡，无任务金手指写使用史，无分级力量写可验证能力边界；不适用项说明原因及等价约束，不硬套仙侠、系统或公司模板。
跨档案核对人物、势力、地点名称、时间线、交通耗时、经济口径、能力边界、关系和伏笔ID；新增提案不得静默覆盖已确认内容，冲突明确列出。
每个分区包含能够指导具体场景的细节，关键机制给触发—行动—结果—代价的示例。数字写单位、周期、依据或估算假设，不能伪造精确度；禁止省略号、略、同上、其余同理等占位。
MD正文与结构化JSON必须内容等价：每个分区、字段、表格、说明和例子均须保留，不能把JSON缩成摘要。长说明用kv条目；表格长解释保留在对应单元格，禁止因排版删除正文。
多个对象分别完整输出并保持名称匹配，禁止混用他人档案。输出预算不足时缩小批次或继续完成当前对象，不压缩必填分区，不把截断草稿冒充完整档案；沿用现有保存确认流程。
