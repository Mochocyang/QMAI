# 同人衍生

## 适用范围

同人创作、二创、衍生文、原作续写、原作番外、AU（架空世界）、OOC（性格重塑）、CP 向、穿书/穿越进原作世界。

**不适用**：原创作品。原创作品请走对应题材 Skill；同人要素只在「存在一部外部原作、其既成事实对本书有权威性」时启用。

## AI 大纲路由约束

- 使用本 Skill 前必须先读取上级目录的 `GENRE_ROUTE_STANDARD.md`。
- 必须先输出**原作正典卡**，再输出题材卡，最后进入总纲、卷纲、章纲、人物或设定生成。
- 本 Skill 只服务 AI 大纲体系，不处理正文协作区的正文生成。
- 本 Skill 与其他题材 Skill **叠加**而非互斥：`同人 + 玄幻` 应同时加载本 Skill 与对应题材 Skill，题材规则负责写法，本 Skill 负责原作边界。

## 核心读者期待

- 读者是**冲着原作来的**：他们认识这些角色，期待的是「还是那个人，但发生了新的事」。
- 角色一崩，全书就废。读者对原作角色的辨识度极其敏感，靠的是动机、说话方式、行为选择，不是名字。
- 读者能接受**新故事**，不能接受**复读原作剧情**——重演原作名场面会被视为偷懒。
- 读者对「原作没交代的部分」有容忍度，对「原作明确交代却被写反」零容忍。

## 同人模式（先确认，再生成）

| 模式 | 语义 | 必须交代 |
|---|---|---|
| `canon` 正典延续 | 填补原作未展示的时间段或视角 | 填哪一段、从谁的视角 |
| `au` 架空世界 | 指明一个分歧点，并严格跟随其后果 | 分歧点是什么、分歧后哪些原作事实仍成立 |
| `ooc` 性格重塑 | 有意的性格偏离 | 偏离的成因与边界 |
| `cp` CP 向 | 关系变化驱动剧情 | 关系起点、推进驱动力 |

用户也可以用一句话自定义模式（例如「原作结局十年后的低魔日后谈」）。自定义模式下，必须把这句话展开成明确的**可改 / 不可改**清单。

## 原作正典卡（每次生成的第一个产出）

在题材卡之前先输出，只写**有原作证据**的内容：

```markdown
# 原作正典卡

## 来源
- 原作：
- 同人模式：
- 容许偏离：
- 证据范围：（本次依据了原作的哪些部分）

## 世界观硬规则
- （不可违背的设定；没有证据的写「原作未交代」）

## 主要人物
### 角色名
- 身份：
- 性格：
- 语言习惯：
- 能力边界：
- 已知信息：（在该时间点他知道什么、不知道什么）
- 标志性限制：

## 关键关系与阵营

## 时间线（已发生的关键事件）

## 禁忌与标志性限制

## 原作未交代（本作可以自由发挥的空白）
- （明确列出留白，避免后续把猜测写成正典）
```

## 与「参考拆文」的分工

QMAI 原有的参考拆解规则要求「不得复用参考作品的人物、设定、剧情、表达」。那条规则约束的是**当作写作范本的另一部作品**，与同人正典的作用对象相反，必须分清：

| | 作用对象 | 规则 |
|---|---|---|
| 参考拆文 / 人格迁移 | 拿来当范本的**其它**作品 | 只学节奏与结构，不得复用人物、设定、剧情、表达 |
| 同人正典 | **本作原作** | 既成事实必须沿用，不得替换成本作原创设定 |

两者都**禁止抄录原句**：同人沿用的是事实，不是文字。名场面用一句话侧面带过即可。

## 创作硬规则

以下六条在任何同人模式下都成立：

1. 原作正典是权威：既成的人物、关系、世界规则、时间线、角色已知信息与标志性限制，不得随意更改。
2. 服从所选同人模式：模式决定哪些可以改、哪些不能改，其余一律按正典处理。
3. 写新的戏剧线，不复读原作场景；新增配角与事件必须服务新线，且能与原作正典区分开。
4. 保留角色辨识度靠动机、认知、节奏和行为选择，不靠抄录原作语句。
5. 原作没有证据时保持留空或向用户发问，绝不把猜测写成正典。
6. 压缩后的资料包是证据，不是臆造缺失正典的许可。

## 大纲生成规则

1. **先定边界，再定故事**：先写清「哪些不能动」，再在这个笼子里设计新戏。
2. **写新线，不复读**：新的戏剧线必须解决原作未解决的问题，或利用原作未展开的空白。
3. **允许偏离必须显式**：任何对原作既成事实的改动，都要写进「容许偏离」；没写进去的一律按正典处理。
4. **新增角色要与原作可区分**：原创配角必须有独立动机，不能只是原角色的影子。
5. **人物一致性优先于戏剧性**：当「这个角色会这么做」与「这样写更好看」冲突时，选前者，除非用户已把该改动列入容许偏离。
6. **时间点必须锚定**：明确本作从原作的哪个时间点接续，并保证角色在该时间点的**已知信息**正确。
7. **留白可以不填**：原作没交代的，可以不解释；不要为了完整性编造体系。

## 章纲生成重点

- 本章必须确认：出场角色的当前状态、他此刻知道什么、他的行为是否符合既定性格。
- 本章不能出现与正典冲突的设定、能力或关系。
- 章尾钩子优先：原作空白处的新线索、关系变化、新的限制或代价。
- 不重演原作场景；如需回指原作事件，用一句话侧面带过，不整段复写。

## 风险与避坑

- **题材偏移风险**：把同人写成原创——读者认不出原作角色。对策：正典卡先行，人物逐项对齐。
- **设定崩坏风险**：给原作角色加原作不存在的能力/身份。对策：能力边界必须来自正典卡。
- **复读风险**：把原作名场面重写一遍当新章节。对策：新线必须解决新问题。
- **信息差错误**：角色说出了他在该时间点不该知道的事。对策：正典卡的「已知信息」逐章核对。
- **猜测升格**：把同人社区的流行说法当成原作正典。对策：证据不足一律写「原作未交代」。
- **偏离失控**：改动越滚越大，最后与所选模式不符。对策：所有偏离进「容许偏离」清单并回看模式。
