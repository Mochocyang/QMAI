# 书名生成（title-forge）

按书架上的作品生成网文风格书名。

> ⚠️ **当前状态：本地测试版，未发布到 GitHub。** 安装方式见下方「本地安装」。

## 它做什么

1. 读取你**书架上的书**：书名、简介、章节数、每本少量正文采样
2. 按你选的风格生成书名候选
3. 在弹窗里展示，可一键复制

## 三种风格

| 风格 | 例子 | 特征 |
|---|---|---|
| **四字格 · 玄奇** | 《诸神鱼戏》 | 4–6 字，意象奇诡，不用"系统/开局/无敌"这类直白词 |
| **玄幻爽文长标题** | 《中午横推诸天》《从满级悟性开始》《洪荒阐教首徒》 | 7–12 字，把金手指/出身/起点直接写进标题 |
| **番茄式 · 事件反转** | 《开局跳楼，沙瑞金被撤，空降汉东》 | 12–22 字，逗号分句，前半句极端情境、后半句抛身份或反转 |

三种风格的写作要求**分别**写死在 `index.js` 的 `STYLES` 里，不是一句"请生成网文标题"能糊过去的——这是这个插件的主要价值。

## 权限

申请 **`fs:shelf-read`**（读书架概要）。

- 它能读到：书名、简介、章节数、每本最多 1200 字的正文采样
- 它读不到：全书正文、书架以外的任何文件
- 上限由**宿主**强制（`MAX_BOOKS_PER_CALL=30`、`MAX_TOTAL_SAMPLE_CHARS=12000`），插件改不了

## 本地安装

### 方式一：从本地目录（开发时用）

```
软件 → 插件 → 添加插件 → 本地目录 → 选 samples/plugins/title-forge
```

### 方式二：打包成 zip 后按 GitHub 形态装

```bash
cd samples/plugins
zip -r title-forge.zip title-forge
```

## 它提供的工具

| 工具 | 用途 |
|---|---|
| `list_shelf_books` | 列出书架上有哪些书（供用户勾选） |
| `collect_writing_material` | 取选中书的简介与正文采样，拼成提示词素材 |
| `list_name_styles` | 返回三种风格的写作要求 |

宿主还有一个声明式 action「生成书名」：它负责表单、调模型和弹窗，把上面三个工具取到的素材喂给模型。

## 自测

```bash
node --test "samples/plugins/title-forge/index.test.mjs"
```

8 条用例，覆盖：三个工具都在、三种风格要求互不重复、宿主 403 时错误可读、空书架有明确说明、缺字段不崩、多本书素材有分隔。

## 目录结构

```
title-forge/
├── plugin.json          # 清单（schema 3）
├── index.js             # 插件本体：三个 MCP 工具 + 三种风格
├── qmai-plugin.mjs      # SDK 运行时（拷进来，插件才能独立分发）
├── index.test.mjs       # 自测
└── README.md
```

`qmai-plugin.mjs` 是 SDK 的副本，**故意拷进来**而不是引用 `sdk/` 目录：插件要能作为一个独立 GitHub 仓库被安装，就不能依赖主仓里的相对路径。

## 已知限制

- **只能生成，不能写回**：生成的书名只能复制。写回书名需要重命名项目目录，风险不对称，暂不支持。
- **素材要先备好**：声明式 action 拿不到书架上下文，所以素材需要先经工具取得、再填进表单。这是当前架构决定的，不是偷懒。
